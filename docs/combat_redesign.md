# 전투 시스템 재설계 (v2)

> 작성일: 2026-08-11
> 기존 턴제(강타/회복/피하기 스팸) → 카드+무기전환 기반 전투로 전환

## 배경: 왜 바꾸나

기존 전투 루프의 문제:
- 마나 포션 무한 구매 → 자원 압박 없음
- 캠프파이어 완전 무료 회복 → 리스크 제로
- 스킬 3개뿐 → "강타-강타-피하기-피하기" 패턴 고착화

## 1. 장비 시스템

| 장비 | 효과 | 비고 |
|---|---|---|
| 검 | 물리 데미지 증가 | 기본템: 나무검 (보너스 없음) |
| 지팡이 | 마법 데미지 증가 | 기본템: 나무 지팡이 (보너스 없음) |
| 방패 | 최대 체력 증가 | 기본템: 나무 방패 (보너스 없음), **상시 패시브** |

### 슬롯/등급 구조
- 검/지팡이/방패 **3슬롯 완전 독립** — 세트 개념 없음. 슬롯마다 각자
  없음/나무/뼈/금 4단계 중 하나를 개별로 장착
  (예: 검=나무, 지팡이=금, 방패=없음 조합 정상)
- 항상 3슬롯 동시 장착 상태로 전투 시작 (기존 "풀도핑" 항목과 동일)
- 등급별 스탯 (초기 추정치, 플레이테스트로 조정):

| 등급 | 검(물리뎀지 보너스) | 지팡이(마법뎀지 보너스) | 방패(최대체력 보너스) |
|---|---|---|---|
| 없음 | +0 | +0 | +0 |
| 나무 | +1 | +1 | +5 |
| 뼈 | +2 | +2 | +10 |
| 금 | +4 | +4 | +20 |

- 획득처:
  - **상자**: 확률적으로 여러 후보 중 하나. 지역별 등급 상한: 마을·숲=나무 /
    동굴=뼈 / 사막·유적=금. **드롭 확률 50%** (꽝이면 기존 골드 보상),
    등급 내 가중치 6:3:1(나무:뼈:금, 상한 이하에서). 배치된 상자는
    현재 마을 2개뿐(나무 상한)
  - **몬스터 처치**: 15% 드롭(85% 꽝), 등급은 동일 6:3:1 가중치
  - **몬스터 처치 확률 드랍, 등급은 몹 종류에 연동**:

    | 몹 | 드롭 등급 |
    |---|---|
    | 오크 (1레벨 퀘스트) | 나무 |
    | 스켈레톤 (2레벨 퀘스트) | 뼈 |
    | 미라 (3레벨, 사막/유적) | 금 |

  - **상점 구매**: 가격 = 나무 5골드 / 뼈 10골드 / 금 15골드 (품목당)
- 시각 표현: 캐릭터/몹 몸에는 안 얹음 (애니메이션 제약 때문에 폐기됨) → **인벤토리/상점 아이콘으로만 표시**

### 무기상점 NPC (신규)
- 현재 미사용 상태인 마을 주민 NPC 하나를 무기상점 상인으로 배치 (술집 안)
- 대사 구조: 유서프 패턴 참고 — "뭘 파세요?" (상점 오픈) / "누구세요?" (자기소개, 상인) / 호감도 오르면 "잘 지내세요?" 정도의 가벼운 일상 대화
- **나중에 추가할 것 (지금 범위 아님)**: 호감도 최고치에서 "잘 지내세요?" 응답으로 무기 선물 지급
- 이 NPC를 다루기 전 `docs/world.md` 먼저 확인해서 기존 설정/톤과 어긋나지 않게 맞출 것
- 판매 품목: 게임 내 모든 장비 9종 (나무/뼈/금 × 검/지팡이/방패)

### 상점 UI — 페이지네이션
- 기존 3행 고정 UI로는 9종 다 못 넣음 → `<`/`>` 버튼으로 3개씩 페이지 전환 (예: "1/3" → "2/3" → "3/3")

## 2. 전투 진입 (풀도핑)

- 포션 섭취 / 버프는 **전투 시작 전에만** 가능
- 검/지팡이/방패 3종 동시 장착하고 전투 시작 (방패는 상시 방어 패시브)
- 전투 시작 후 인벤토리 잠금, 포션 사용 불가 — 오직 손패로만 승부

## 3. 카드 & 드로우

- 매 턴 시작 시 **5장 드로우**, 5장 전부 자유롭게 사용 가능
- 카드 종류:
  - 🔴 물리 카드 — 검 장착 상태에서 위력 극대화
  - 🔵 마법 카드 — 지팡이 장착 상태에서 위력 극대화
  - 🟢 공용 카드 — 무기 상태 무관 (실제 턴당 공격 횟수를 자연스럽게 제한하는 역할)
    - 체력 회복
    - 마나 회복
    - 방어 (다음 피격 데미지 감소)
    - 피하기 (회피)

## 4. 실시간 무기 스위칭 ("딸깍")

- 전투 중 상시 [검 / 지팡이] 표시, 버튼으로 **턴 소모 없이 즉시 전환**
- 검: 물리 데미지 패시브 / 지팡이: 마법 데미지 패시브
- **전환 자체는 턴당 최대 3회로 제한** (전환 스팸으로 게이지 조작하는 것 방지 목적은 아니고—게이지 감소는 카드 사용에 연동되어 있어 스팸 이득이 없음—과도한 전환 클릭 자체를 막기 위한 별도 제한)

### 4-1. 적 저항 패턴 (핵심 재미 요소)
- 매 턴 시작 시 **30% 확률**로 몹이 저항(물리 또는 마법 중 랜덤) 활성화
- 활성화되면 그 턴 동안 지속, 다음 턴에 다시 확률 판정
- 지금은 몹 종류 차별화 없음 (보스 등 특수 패턴은 나중 단계에서)
- 저항과 안 맞는 무기로 공격 시 데미지 저하 → 플레이어가 무기 전환으로 카운터해야 함

### 4-2. 무기 과열 게이지
- 무기별로 별도 게이지 보유 (검 게이지 / 지팡이 게이지)
- 해당 무기로 스킬(카드) 사용 시마다 **+25%**
- **4번 연속 사용 = 100% 과부하** → 페널티 발동
- 다른 무기로 전환해서 그 무기 스킬을 쓰면, 원래 무기 게이지가 **-25% 회복**
- 저항 패턴이 없어도 주기적 무기 교체를 유도하는 역할

## 5. 도망가기

- 카드 밖 별도 버튼, 전투 이탈
- **HP가 최대치의 50% 미만이면 도망 불가** (기존 `battle_scene.gd`의 `FLEE_HP_THRESHOLD` 게이팅 유지)
- HP 50% 이상일 땐 도망 가능하되, **골드 1~10 사이 랜덤 소비** (무한 도망-재시작 리롤 방지 + 매번 다른 손해라 도박성 긴장감)

## 6. 마나

- 기존 시스템 유지
- 용도: **🔵 마법 카드 사용 시 마나 소모** (물리 카드는 마나 무관)
- 마나가 부족하면 마법 카드 사용 불가 → 지팡이 전환 압박이 이중으로 걸림 (과열 + 마나)

## 7. 밸런스

- 몹 HP 전반적으로 상향, 플레이테스트하며 패치
- 정확한 수치는 구현 후 조정 대상 (초기값 추정치로 시작)

## 미해결 / 플레이테스트하며 정할 것

- [ ] 각 카드의 정확한 데미지/회복량 수치
- [ ] 마나 소모량 (마법 카드별로 동일한지, 카드마다 다른지)
- [ ] 저항 시 데미지 저하 폭 (몇 % 감소인지)
- [ ] **밸런스 관찰(2026-08-11 첫 플레이테스트)**: 과열 게이지가 꽤 끈적함 —
      손패에 반대 속성 카드가 없거나 마나 부족하면 3~4턴 동안 한쪽 무기가
      묶이는 현상 발생. 공용 카드 비중/회복량 조정 후보

## v3 계획: 다인전 (2026-08-16 시작)

### 배경
카드 5장(다양한 선택)에 비해 몹은 고정 패턴 하나뿐이라 체감 난이도가
떨어짐. 단순 수치 상향은 임시방편이라 구조적으로 다인전 도입.

### 확정 사항
- **필드 잡몹 전투: 1~3마리 랜덤 등장, 2마리 확률이 제일 높음** (1/3은
  드물게). 기존 고정 1:1 전투는 사라짐.
- 사막 보스몹이 잡몹을 소환하는 연출(최대 1:5까지)은 **나중에** — 지금
  범위 아님
- 디버프/버프 지속 턴수는 **카드마다 개별 지정** (카드 설계 단계에서
  하나씩 정함)
- 타겟팅 UI: 카드 클릭 → 내 캐릭터/각 적 캐릭터 밑에 원 표시 → 화살표로
  원하는 적 선택
- 디버프/버프 카드 예시(추후 설계): 상대 물리/마법 저항 감소, 데미지
  감소(약화), 방어력 감소, 기절(한 턴 행동 불가) 등
- 적도 시각적 스킬 이펙트 + "가짜" 마나바(실제 자원 시스템 아니어도
  됨, 랜덤으로 오르내리며 "스킬 쓰는 것처럼" 보이기만 하면 충분) 추가 예정
- 적도 플레이어처럼 "공격하는" 느낌(이펙트 동반)으로
