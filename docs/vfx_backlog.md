# VFX 백로그

지역별로 나중에 하나씩 붙일 수 있는 앰비언트 연출 아이디어 목록. 아직 구현 안 함 — 기록만.
(갓레이/블룸은 이미 구현됨: `systems/god_rays.gd`, `systems/bloom_controller.gd`)

- **평원**: 민들레씨/꽃가루가 바람에 날림, 흩날리는 꽃잎 — `world/leaf_emitter.gd`의 낙엽과
  같은 구조(카메라 뷰 기준 스폰 + 오브젝트 풀)를 재사용할 수 있을 것
- **밤/신비로운 숲**: 반딧불이(느리게 떠다니며 밝기가 깜빡임), 마법 광석 가루(반짝이는 작은 입자)
- **사막/황무지**: 먼지·모래바람(화면을 가로지르는 옅은 안개 띠), 굴러다니는 회전초(월드
  오브젝트로 굴러다니다 화면 밖으로 사라짐)
- **습지/던전**: 포자·가스(바닥에서 천천히 피어오르는 반투명 입자)
- **날씨 화면 효과**: 비, 서리 낀 화면 테두리(비네트류 오버레이), 번개 칠 때 화면 전체 흰색 플래시
- **물 상호작용**: 캐릭터가 물에 닿았을 때 물결 파문, 수면 근처 증기
- **안개/고도감 레이어**: 화면 하단이 흐려지는 원경 안개로 거리감 표현
